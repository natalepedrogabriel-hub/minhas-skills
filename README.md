# Minhas Skills para o Claude

Coleção de skills que criei para o Claude. Cada pasta é uma skill.

## Skills disponíveis

| Skill | O que faz | Download |
| --- | --- | --- |
| Ranqueador de currículos | Ranqueia candidatos para uma vaga com critérios e pesos escolhidos pela empresa, justifica cada nota e sugere perguntas de entrevista para o top 3. | [Baixar](https://github.com/natalepedrogabriel-hub/minhas-skills/releases/tag/ranqueador-curriculos-v1) |

## Como instalar

1. Clique em **Baixar** na skill desejada e baixe o arquivo `.zip`.
2. No Claude, vá em **Configurações → Capacidades → Skills**.
3. Clique em **Upload a skill** e selecione o `.zip`.

Pronto: o Claude passa a usar a skill sozinho quando o pedido combinar com ela.

## Observação

As skills não guardam dados de clientes ou candidatos. Use com responsabilidade e de acordo com a LGPD.
